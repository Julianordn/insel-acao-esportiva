# INSEL Ação Esportiva

**Sistema Web para Gestão de Projetos Esportivos**

## Sobre o projeto

O INSEL Ação Esportiva é um sistema web desenvolvido como projeto de extensão universitária do curso de Análise e Desenvolvimento de Sistemas da Uninter.

O objetivo é auxiliar na organização e no gerenciamento de projetos esportivos, facilitando o controle de alunos, turmas, atividades e frequências.

A proposta é utilizar a tecnologia para contribuir com a organização das informações e apoiar o trabalho administrativo de projetos esportivos.

## Funcionalidades

- Cadastro e gerenciamento de alunos.
- Cadastro e gerenciamento de projetos.
- Organização de núcleos e turmas.
- Registro de atividades.
- Controle de frequência dos alunos.
- Consulta de relatórios.
- Geração de relatórios em planilhas Excel.
- Sistema de acesso com login.

## Tecnologias utilizadas

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript
- OpenPyXL

## Estrutura do projeto

- `app.py` — aplicação principal.
- `templates/` — páginas HTML do sistema.
- `static/` — arquivos estáticos, como CSS e imagens.
- `banco_demonstracao.db` — banco de dados com informações fictícias para demonstração.
- `requirements.txt` — dependências do projeto.
- `instalar.bat` — instalação das dependências.
- `iniciar.bat` — inicialização do sistema.

## Como instalar e executar

**Requisitos:** Python instalado no computador.

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo `instalar.bat`.
4. Aguarde a instalação das dependências.
5. Execute o arquivo `iniciar.bat`.
6. Abra o navegador e acesse:

`http://127.0.0.1:5000`

## Banco de dados

O projeto disponibiliza um banco de dados de demonstração com informações fictícias, permitindo testar as funcionalidades do sistema.
